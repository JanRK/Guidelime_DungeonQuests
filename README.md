# Guidelime_DungeonQuests

Quest guides for the dungeons and raids of WoW Forever. The addon runs inside [Guidelime](https://www.curseforge.com/wow/addons/guidelime), which must be installed.

Each guide lists the quests for one dungeon, raid or Scarlet Monastery wing. It covers where to pick up each quest, what to do, and where to turn it in. Most dungeon quests need a chain of earlier quests, and the guide includes that chain.

## Install

1. Install Guidelime.
2. Install this addon with one of:
   - [WowUp-CF](https://wowup.io/): choose your WoW Forever installation, then "Install from URL" with `https://github.com/JanRK/Guidelime_DungeonQuests`. WowUp-CF also offers updates.
   - By hand: copy the `Guidelime_DungeonQuests` folder into `Interface/AddOns/` in your WoW Forever folder.
3. Start the game and open Guidelime. The guides are listed under "DungeonQuests - JanRK".

## Guides

The guide name starts with the level range, for example "18-21 Deadmines". When you finish a guide, Guidelime offers the next one in level order.

Some guides are not written yet. They show "This guide is not ready yet. Skip to the next guide."

Most written guides cover only Horde. Alliance steps are being added.

Extra guides:

- Library books: one guide per faction for each reward tier (10, 20 and 25 books). Tier 10 also has a version that picks up the Cozy Sleeping Bag on the way.
- Cozy Sleeping Bag: a short guide for that quest alone.

## Report a problem

The guides have not been tested in game yet. If a step is wrong, open an issue at [JanRK/Guidelime_DungeonQuests](https://github.com/JanRK/Guidelime_DungeonQuests/issues). Include the guide name, the step, and what you saw in game.
